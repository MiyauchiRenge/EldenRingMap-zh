# EldenRingMap 中文版

把《艾尔登法环》的地图做成**本地交互式网页**：地图瓦片、物品图标与全部标记数据都由**你自己电脑上的
游戏文件**在本机生成，仓库里只有代码与文档。

[English](README.en.md) · [详细说明（汉化与技术）](docs/汉化说明.md)

## 二、功能

* 交互式大地图：地表、地底、DLC 各区，支持缩放与图层面板；
* 标记与分类：赐福、据点、Boss、物品、采集点、商人、敌人掉落等，分类行可勾选、可统计进度；
* 物品图标：每个标记显示物品自己的图标（本机从游戏图集提取）；
* 数据全部本地生成：`regulation.bin`、`Data*.bhd`、MSB、EMEVD、FMG、TPF 图集、`ER0000.sl2`；
* 存档相关：读取存档中的已拾取状态与角色位置，用于自查与补点（详见第四节）；
* 两种启动方式：`Start Map.bat`（可见控制台）与 `Start Map.vbs`（隐藏窗口）；关闭网页后服务自行退出；
* 简体中文界面与游戏官方中文名称。

## 四、思路（机制）

**采集物**：地图上的资产部件名形如 `AEG{xxx}_{yyy}_{instance}`，其中 `AEGxxx_yyy = xxx*1000+yyy`
是 `AssetEnvironmentGeometryParam` 的行号；该行的字段 `pickUpItemLotParamId`（`+0xB8`）指向
`ItemLotParam` 中的 lot，即"这个采集点给什么"；坐标取自部件记录本身。因此采集点可以完全枚举：
该表 24,106 行中 321 行带拾取 lot，扫描 1,248 张地图的 621,538 个部件后得到 19,263 个采集点。

**存档世界状态**：存档槽中紧随事件旗标之后有两个区块——`MOEG`（WorldGeomMan，已破坏/已拾取的
资产）与 `FOEG`（WorldGeomMan2，永久拾取的一次性节点），条目 8 字节：
`key = instance << 15 | state`、`model = 10000000 + AEG id`，按地图分段。采集物不写事件旗标，
因此"采过什么"以这两个区块为准。

**自查与验收**：

| 工具 | 用途 |
| --- | --- |
| `tools/dev/verify_with_save.py` | 用存档旗标列出"存档中有、地图上没有"的条目 |
| `tools/dev/world_gaps.py` | 筛选是否被世界对象引用 |
| `tools/dev/gap_classify.py` | 按证据区分真漏点与无世界位置（任务奖励、无名内部条目） |
| `tools/dev/place_from_save.py` | 读不到位置的条目：站到该处存档，用角色坐标落点（标注来源，仅本机） |

验收结果：存档 `FOEG` 已拾取节点 321 / 321 均可在地图上找到；存档旗标版漏点 0；采集物图标
114 / 114 齐备；坐标核对误差 0.2 像素。数量：幽影树碎片 46 个点位 / 50 个物品，灵灰 23 个点位 /
25 个物品（部分点位一次给两个，标记内含数量）。

**已知限制**：全局脚本直接发放的物品没有世界物件，无法给出坐标；地图事件（Boss 击杀）发放的
碎片以 Boss 标记为锚点；`m10_01_00` 一类子图需先换算到母图坐标系再投影（已实现）；采集点的
"一次性 / 可刷新"分流尚未实现，目前采集点统一按位置统计、不计入收集进度。

## 五、安装

```
1. 运行 Setup.bat（13 步，全部在本机生成数据）
2. 运行 Start Map.bat（可见控制台）或 Start Map.vbs（隐藏窗口）
3. 浏览器打开提示的地址
```

Linux：`setup-linux.sh` 与 `start-map.sh`。详细步骤与故障排查见
[docs/汉化说明.md](docs/汉化说明.md)。

## 六、更新记录

记录修正与增补；正文其余部分是稳定说明。

* **商人**：数量判定为 20 个（`c3200` 部件 29 个，其中 8 个指向占位 NPC 行且所在图没有驮马）。
  命名取同 master 内最近的赐福（≤300 px），过远则取最近的非 Boss 地标，人工指定优先。
* **子图坐标**：只有 `place()` 无法投影的地图（如 `m10_01_00`）才平移进母图坐标系；能正常投影的
  地图不再平移，修正了一处商人标记偏移 256 px、落到地形高度不符位置的问题。
* **商人铃珠**：击杀商人掉落的铃珠与其主人坐标重合（0 px），商人标记带 `dropsBell` 字段。
* **商店货架**：`ShopLineupParam` 可读出售价、单次数量与库存旗标；该表与 `NpcParam` 均无商户归属
  字段，因此货架行只登记、不落点。
* **采集点**：id 加入部件偏移，消除同名部件共用一个 id 造成的重复标记。
* **重复判定按图层区分**：拾取类一个点一个 lot，同 lot 同坐标视为重复并合并；采集点每图每物品
  一个 lot，同 lot 属正常现象，予以保留。
* **分类**：龟裂壶、大龟裂壶、调香瓶、仪式壶、制作笔记各自成类，商店限定道具单列；分类要显示为
  侧栏行，必须登记在 `app.js` 的 `EXTRA_CATS` 中。
* **界面提示**："附近的无名地标"只取 grace / poi / region / landmark / fragment 五类，半径 150 px。
* **标签**：中英标签分属 `i18n.js` 的 `en` 与 `zh` 两个块，同一键每块各写一次。
* **文档结构**：`docs/汉化说明.md` 只保留机制与格式说明；过程性记录（曾试验后撤回的做法、脚本
  演进、待办）不再保留在说明文档中。
